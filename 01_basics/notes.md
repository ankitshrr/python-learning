# Chapter 1: Python Basics

## Comments
### Key Points
- Used to explain code.
- Python ignores comments during execution.
- Single-line comments use `#`.
- Multi-line comment use '''.

---

## Indentation
### Key Points
- Python uses indentation to defince block.
- Incorrect indentation cause "IndentationError"
- standard is 4 **4 spaces**

---

## Input & Output
### `input()`
- Takes input from the user.
- Always returns a `str`.

### `print()`
- Displays output.

---

## Type Casting
### Definition
Converts one data type to another.

### Functions
- `int()`
- `float()`
- `str()`
- `bool()`
