## 📚 Topics Covered

| # | Chapter | Key Concepts |
|---|---------|-------------|
| 01 | **Basics** | `print`, comments, indentation, input/output, operators, math functions |
| 02 | **Variables & Data Types** | Typecasting, booleans, `is` operator, multiple assignment |
| 03 | **Strings** | Slicing, methods, escape sequences |
| 04 | **Lists & Tuples** | Sequential data, mutability, methods |
| 05 | **Dictionaries & Sets** | Key-value pairs, set operations |
| 06 | **Conditionals** | `if` / `elif` / `else`, conditional expressions |
| 07 | **Loops** | `for`, `while`, `enumerate`, `zip`, `break` / `continue` |
| 08 | **Functions & Recursion** | Parameters, return values, lambda, recursion |
| 09 | **File Handling** | Reading, writing, appending, `with` statement |
| 10 | **OOP** | Classes, objects, constructors, class vs instance attributes |
| 11 | **Modules** | Imports and built-in modules |
| 12 | **Playground** | Small demos, experiments, and tricky exercises |

---

## 🚀 How to Use

1. Learn the lessons in order from `01_basics/` through `11_modules/`.
2. Practice with the `exercises/` folder inside each chapter.
3. Build small apps in `projects/` after you finish the core lessons.
4. Use `playground/` for quick experiments and revision.
